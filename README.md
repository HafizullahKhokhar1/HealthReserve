# HealthReserve

HealthReserve is a full-stack, AI-integrated healthcare platform designed to connect:

- Doctors and patients directly
- Labs for diagnostics and consultation
- Pharmacies for prescription support

## Project status

This repository is currently in active development and will be updated regularly.

## View-only policy

The project owner intends this project to be **view-only** for the public.

- Visitors may view the project information.
- Reuse, redistribution, and downloading for reuse are not permitted without written permission.

## Important note about GitHub visibility

If a repository is public on GitHub, GitHub technically allows users to clone/download it.  
To keep code non-downloadable, keep the source repository **private** and deploy only the running website publicly.
